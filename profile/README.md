## 🌱 Worum es geht

Wer einen guten Gartenbau-Betrieb sucht, verlässt sich meist auf Hörensagen. Und wer einen guten Betrieb führt, hat selten Zeit für Marketing.

**[gartenbauheld.de](https://gartenbauheld.de)** schließt diese Lücke. Auftraggeber finden dort Fachbetriebe aus ihrer Region, vergleichen sie und fragen direkt an. Das reicht vom wöchentlichen Rasenschnitt bis zur kompletten Gartenneuanlage.

> 💡 **Unser Grundprinzip:** Sichtbarkeit soll nicht davon abhängen, wer das größte Werbebudget hat, sondern davon, wer gute Arbeit leistet.

---

## 🧭 So funktioniert's

```text
   🔍  1. Suchen            🌳  2. Vergleichen          ✉️  3. Kostenlos anfragen
   ───────────────          ──────────────────          ─────────────────────────
   Leistung + PLZ    ──▶    Profile, Fotos &     ──▶    Projekt einmal beschreiben,
   eingeben                 echte Bewertungen           an mehrere Betriebe senden
```

| | |
|---|---|
| ✅ **Kostenlos & unverbindlich** | Anfragen kosten Auftraggeber nichts |
| ✅ **Verifizierte Fachbetriebe** | Geprüfte Profile, klar gekennzeichnet |
| ✅ **Direkter Kontakt** | Keine Vermittlungsgebühr, keine Provision |
| ✅ **Echte Bewertungen** | Bewerten dürfen nur Auftraggeber, die über die Plattform angefragt haben |

## 👷 Für Gartenbau-Betriebe

Sie führen einen Garten- und Landschaftsbaubetrieb? Dann werden Sie sichtbar, ohne Werbebudget:

- 💚 **Basiseintrag dauerhaft kostenlos**: ohne Laufzeit, ohne Provision, ohne versteckte Kosten
- 📬 **Anfragen direkt von Auftraggebern** aus Ihrer Region
- ⭐ **Faire Bewertungen**: Sie können Bewertungen kommentieren, aber niemand kann sie kaufen
- 🏷️ **Bestehendes Profil übernehmen**, falls Ihr Betrieb schon gelistet ist

**[➜ Betrieb kostenlos eintragen](https://gartenbauheld.de/eintragen)** · [Anleitung für Betriebe](https://gartenbauheld.de/anleitung-fuer-betriebe)
